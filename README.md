# 词间妙记 · Words in Bloom

一个本地运行的考研单词学习网站，数据取自桌面文档《英语.xlsx》的「考研单词-5920」工作表 **Lesson 1–40（共 2934 词）**，并保留书中的词群标签（如“bar 相关”“钱 相关”）。

目前已预置 **1230 个单词**的书中「联想记忆法」妙计（来源：桌面的 `lesson1~4.txt` 和「英语」文件夹里的 4 个 docx），这些内容可以继续自由修改。
所有单词释义都已标注词性（名词 n. / 动词 v. / 形容词 adj. 等），并支持在线朗读（🔊）。

## 怎么用

1. 直接双击打开 `index.html`（推荐用 Chrome / Edge），无需安装任何东西，也无需联网。
2. 所有数据都保存在浏览器本地的 localStorage 中，不会上传。

## 功能

- **首页**：学习进度看板（已掌握/学习中/待复习/收藏/连续学习）、快捷入口、专注计时器、你的“50 天轮回计划”表。
- **50 天轮回计划**：数字 = 组号（1–20），每组 = 半个单元 = 2 个 lesson（第 1 组=Lesson 1–2，第 2 组=Lesson 3–4 …… 第 20 组=Lesson 39–40）。第 1–20 天上午新背、晚上复习；第 21–50 天按艾宾浩斯间隔纯复习。
- **词集库**：可按 10 个单元、20 个组或 40 个课时浏览，带进度条，可一键进入沉浸学习/卡片/测试。
- **沉浸学习**：逐词浏览；每个单词都有可编辑的 **“我的妙计”** 输入框，自动保存；支持左/右方向键切换、搜索跳转、标记认识/模糊/不认识、收藏；可勾选“**未掌握优先**”把没掌握的词排到最前（已掌握的按原顺序排在后面）。
- **记忆卡片**：点击翻面，按“认识 / 模糊 / 不认识”记录状态；支持「← 上一个 / 下一个 →」前后翻页（不会越过还没答过的新词）、随机顺序、待复习优先。
- **卡片断点保存**：背到一半离开再回来时，会显示“上次背到第 X / Y 个单词”，可一键「继续」或「重新开始」；错词可单独重练。
- **语音朗读**：沉浸学习、记忆卡片、妙计手账、收藏夹和测试里都有 🔊 朗读按钮；「设置」里可以**分别**开关“沉浸学习自动发音”（默认关）和“记忆卡片自动发音”（默认开）。
- **切换语音**：「设置 → 朗读语音」可选择浏览器里的语音，支持**搜索、只看离线、试听**和调语速。带〔在线〕标记的是联网语音（云端合成，有明显延迟），〔本地〕标记的是离线语音（即时）；想要低延迟勾选“只看离线”即可。Windows 语音设置里装的本地自然语音不一定会被浏览器暴露给网页，这是浏览器限制；列表里能选什么取决于浏览器。
- **记忆测试**：四选一（看词选义 / 看义选词），答错的词自动标记为待复习。
- **收藏夹**：集中查看收藏的词，也可以直接补妙计。
- **妙计手账**：全量单词的妙计编辑页，支持搜索、按单元/填写状态筛选、分页加载——看视频时记下灵感的最佳入口。
- **设置**：外观主题（粉色 / 浅蓝 / 夜间灰）、导出/导入 JSON 备份、重置全部数据。

首次打开时，Lesson 1–4 中已有书中「联想」的单词会自动填入妙计（只填空，不会覆盖你自己写过的内容）。

## 妙计覆盖情况（按站点课时统计）

总计 1230 / 2934（42%）。各课时覆盖：Lesson 1–4 约 30–45%，Lesson 7–23、25–39 大多在 30–68%，以下是明显空白：

- **Lesson 5、6**：0%——4 份 docx 里没有任何这两个课时的内容；
- **Lesson 18、24**：文档里没有对应课时（`lesson15-23.docx` 从 17 直接跳到 19，标题写“15-24”但实际没有 18 和 24）；
- **Lesson 24**：仅 6%（来自其他课时按单词匹配到的少量词条）；
- **Lesson 40**：9%——文档明确写了该课多为“逻辑连接词无联想记忆”；
- **Lesson 39**：26%，相对偏低。

其余课时均非整课空白（书中本来就只有一部分“趣讲”单词配了联想，这是正常现象）。如果后续拿到 Lesson 5、6、24（以及 40）的联想内容，直接按同样格式给我即可。

## 妙计怎么填

在「沉浸学习」或「妙计手账」里找到单词，直接在输入框写下谐音、联想、小故事等，停顿约半秒即自动保存（出现绿色“已保存 ✓”）。

建议定期在「设置」或「妙计手账」里点“导出备份”，把 JSON 文件保存到别处，防止误清浏览器数据。

> 说明：朗读使用的是浏览器自带的英文语音（如 Edge 的 Microsoft 语音），无需联网，但首次使用可能需要系统已安装英文语音包。

## 数据存在哪里？移动文件夹会丢进度吗？

妙计、学习进度、收藏和测试记录都存在**浏览器**里（localStorage），并不在文件夹内，而且和当前文件夹路径（file:// 地址）绑定：

- 原地使用：数据一直都在，正常刷新不会丢。
- 移动/重命名整个文件夹：新路径会被浏览器当成新的存储位置，所以打开后进度看起来“没了”（旧位置的旧数据还在，只是新位置读不到）。
- 解决办法：移动前在「设置」或「妙计手账」里点“导出备份”，把 JSON 文件带过去；在新位置打开后再“导入备份”，进度和妙计就都回来了。
- 另外，清除浏览器缓存/网站数据也会清掉 localStorage，所以养成定期导出的习惯最稳妥。

## 手机端使用（PWA）

网站已经升级为 PWA（可安装的网页应用），并支持云端同步：

1. 把网站部署到网上。注意：`workers.dev` / `pages.dev` / `netlify.app` 等海外域名在国内经常打不开，**国内用户建议用腾讯云 COS 或阿里云 OSS 的静态网站托管**（默认域名免备案、国内直连，需实名认证），或 GitHub Pages（国内一般可用但不保证）；
2. 手机 Edge/Chrome 打开网址后，在浏览器菜单里点「添加到主屏幕 / 安装应用」；
3. 桌面上会出现「词间妙记」图标，点开即全屏应用，首次联网打开后支持离线使用。

手机上的语音：Android 版 Edge 的朗读走系统 TTS（Google 语音引擎），在手机「设置 → 系统 → 语言与输入法 → 文字转语音输出」里安装 English (US) 等离线语音包即可低延迟朗读；网站「设置 → 朗读语音」里勾选「只看离线」就能直接选到。iOS 版 Edge 使用系统语音，无需额外设置。

## 账号与云端同步（Supabase 免费档）

网站内置了 Supabase 连接配置（`js/supabase-config.js`，anon 公钥可在浏览器公开）。**注册/登录同一账号后，手机和电脑自动共用同一份数据**，自动合并、较新修改优先；不用再在每台设备上填写 URL 和密钥。

一次性配置（约 10 分钟，免费）：

1. 打开 [supabase.com](https://supabase.com) 注册账号并创建项目（选 Free 档）；
2. 左侧 **Authentication → Sign In / Providers**，确认 **Email** 提供商已启用（默认开启）；建议顺手关掉 Email 的 **Confirm email** 开关，这样注册后立刻就能登录；
3. 左侧 **SQL Editor** → New query，粘贴下面的 SQL 并运行（每人只允许读写自己的数据行）：

```sql
create table if not exists user_data (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table user_data enable row level security;
create policy "own row"
  on user_data for all
  to authenticated
  using (auth.uid()::text = id)
  with check (auth.uid()::text = id);
```

如果之前已经用旧版建过表，只需把策略换成上面的（先执行 `drop policy if exists "shared row for authenticated users" on user_data;` 再执行上面的建策略语句）。

4. 把 `js/supabase-config.js` 里的 URL 和 key 换成你自己项目的（当前文件里已内置你的项目配置，可跳过）；
5. 电脑上打开网站 → 设置 → 账号与云端同步 → 注册/登录 → 点「立即同步」（把你电脑上的数据上传到你的账号）；
6. 手机上打开同一个网址 → 登录同一账号，数据自动拉取。

说明：
- 同步按「键级合并，修改时间较新者优先」，两端最终一致；
- 出问题时可用「本地覆盖云端」强制把本地数据推上去；
- 数据按登录账号隔离（每人一行），其他人即使打开网站也看不到你的数据；
- 电脑上继续双击 index.html 使用也完全可以（离线优先，配置同步后自动云端备份）。
